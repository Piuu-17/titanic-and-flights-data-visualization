# Data Analysis and Visualization with Seaborn 📊

This repository contains a comprehensive Bivariate and Multivariate Exploratory Data Analysis (EDA) notebook leveraging Python's powerful data science libraries—**Pandas** and **Seaborn**—to uncover patterns, behaviors, and historical insights from classic datasets.

## Overview

The primary focus of this project is demonstrating advanced data visualization techniques, resolving common grouping anomalies, and practicing pivot tables for matrix visualizations. 

### Key Analyses Included:
1. **Titanic Survival Factors:** Investigating passenger demographics (`Age`, `Pclass`) against survival rates using custom distribution plots, crosstabs, and annotated heatmaps.
2. **Airline Passenger Growth:** Tracking monthly and yearly flight trends (`flights` dataset) through grouped line plots and structured pivot-table heatmaps to see seasonal travel peaks.

##  Tech Stack & Libraries
*   **Python 3**
*   **Pandas** (Data manipulation and grouping)
*   **Seaborn** (Advanced statistical data visualization)
*   **Matplotlib** (Plot customization)

##  Key Insights & Visualizations

###  Titanic Dataset
*   **Class vs. Survival Heatmap:** A visual matrix proving that passenger class (`Pclass`) was highly correlated with survival chance, showing the highest casualty frequencies in 3rd class.
*   **Age Distribution:** Utilizing modern `histplot` and `kdeplot` distribution tracking to observe age concentrations among survivors versus non-survivors.

###  Flights Dataset
*   **Yearly Passenger Growth:** Line plots mapping the steady upward trajectory of global aviation travelers year-over-year.
*   **Seasonal Heatmap Matrix:** A flight traffic intensity map highlighting that the summer months (July and August) consistently hit peak passenger volume across multiple decades.
